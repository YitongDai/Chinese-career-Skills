# 机会搜索与 Tracker

## 搜索顺序

1. 官方招聘网站、官方公众号或政府国资招聘渠道；
2. 学校就业平台及雇主宣讲；
3. 可信招聘平台；
4. 校友、员工和招聘人员；
5. 行业协会、比赛、实验室、开源项目与活动。

组合搜索词：`岗位族 + 同义岗位名 + 地区 + 届别/毕业年份 + 实习/校招`。财务方向扩展财务管理、FP&A、财务 BP、司库、预算、经营分析、内审、风控、合规、投资管理等词，不只搜索“财务管培”。

## Tracker 字段

记录：机构、性质、行业、岗位、部门、城市、来源 URL、发布日期、截止日期、学历/专业、毕业窗口、学历认证、工作授权、语言/证书、流程、JD 关键词、材料版本、状态、最后核验日、下一动作、个人匹配判断、历史年份、下一届预测及预测依据。

区分历史事实和预测。预测使用日期区间并说明依据；每次正式投递前重新核验。

## 资格核验

优先引用官方原文。单独比较课程完成日、毕业证日、学位证日和留服认证日。若信息冲突，记录冲突来源并建议联系招聘方，不替招聘方作资格承诺。

## 漏斗管理

状态统一为：发现、待核验、待投递、已投递、测评、面试、Offer、拒绝、撤回、过期。每周统计各环节数量和转化率；样本过小时只描述趋势，不下强结论。

## Networking

联系信息应包含具体共同点、一个可回答的问题和低压力收尾。先进行信息访谈，再在确有匹配且关系允许时询问内推。首次未回复可在 5–7 个工作日后跟进一次；之后停止催促。

模板：

> 您好，我是[背景概述]，正在了解[岗位/团队]。我注意到您有[具体相关经历]，希望请教[一个具体问题]。如果方便，我很感谢您用几句话分享；若近期忙碌也完全理解。
