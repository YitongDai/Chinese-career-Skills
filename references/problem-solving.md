# 求职故障诊断

统一输出：症状、三项以内原因假设、验证数据、优先修复、两周观察指标和调整阈值。

| 症状 | 优先检查 | 常见修复 |
|---|---|---|
| 投递多无面试 | 资格、岗位相关性、版本、渠道 | 收窄岗位族；核验毕业窗口；重写前 1/3；增加定向渠道 |
| 测评失败 | 分题型正确率、用时、环境 | 单项训练；错题分类；限时复测 |
| 一面后失败 | 证据深度、动机、追问稳定性 | 复盘原问题；补事实；连续重答 |
| 后轮失败 | 岗位判断、商业理解、团队匹配 | 强化专业案例；准备决策与反思 |
| 表达混乱 | 是否直接回答、结构、例子长度 | 先结论；一个例子；限时录音 |
| 群面弱 | 是否推进共同目标 | 练习结构化、计时、总结和邀请他人 |
| 低 GPA/空窗/转专业 | 事实解释与现时证据 | 简洁承认；说明行动；用近期证据收尾 |
| 长期无回复 | 时间、渠道、流程节点 | 礼貌跟进一次；继续其他机会 |

## 诈骗与安全

警惕付费内推、先交培训费、私人账户收款、非官方域名索取证件、未经面试直接录取、要求安装未知软件或提供验证码。暂停操作，通过公司官网独立查找联系方式核验。保存证据；必要时向平台、学校或当地机构举报。

## 歧视、骚扰与不合理要求

记录时间、渠道和原话，保存证据并优先保障人身安全。不要擅自公开第三方个人信息。根据所在地区咨询学校职业中心、公司合规渠道或合格专业人士。

## 求职耗竭

降低并行岗位族，设置每周无求职时段，将目标改为可控过程指标。若焦虑或低落持续影响睡眠、学习或安全，鼓励联系可信任的人和专业支持；不要把心理健康问题简化为效率问题。
